# AI Work Area

This directory is the only place where AI agents may maintain project
planning/interface notes.

Canonical project policy remains in `docs/*.md`.

## Files

  File                     Purpose
  ------------------------ --------------------------------------------
  `team-1-backend.md`      backend/platform work
  `team-2-simulation.md`   phishing simulation channels
  `team-3-analysis.md`     analysis, inspection, security
  `team-4-console.md`      analyst console
  `integration.md`         cross-team contracts and integration state
  `ai-task-template.md`    reusable task format

## Rule

AI agents may edit these files.

AI agents must not edit `docs/*.md`.

## How to use these files

At the start of a task:

1.  read `docs/AI.md`;
2.  read this file;
3.  read the relevant team file;
4.  inspect the source tree;
5.  update the task state in the relevant AI file if coordination
    changes.

Do not turn these files into a second copy of the entire architecture
documentation.
